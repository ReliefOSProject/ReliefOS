# ReliefWord

ReliefWord 是 ReliefOS Xorg 桌面内置的 C++17 / FLTK 文字处理器。可以从开始菜单的办公应用分类启动，也可以运行 `reliefword [文档.rword | 文本.txt | 页面.html]`。Fileman 默认用它打开 `.rword`；TXT 和 HTML 继续采用现有文件关联，也可以在 ReliefWord 内导入。

## 编辑与排版

直接点击白纸输入文字，拖动选择内容。中文显示使用系统字体，中文输入由 Xorg 会话输入法提供，也支持 UTF-8 剪贴板。左右键和删除按组合字符移动；当前覆盖常见组合符、变体选择符、emoji 修饰符、ZWJ 和地区标志序列，不提供完整的双向文字排版。

“开始”功能区提供剪贴板、字体族、字号、粗体、斜体、下划线、删除线、文字颜色和高亮。字号可选择或输入 6–96 磅，输入后按 Enter 应用。正文、标题、标题 1 和标题 2 预设可以快速整理文档。段落支持左、中、右、两端对齐，以及项目符号、编号和缩进；“段落”对话框可以设置首行缩进、段前段后间距和行距。

“页面布局”设置 A4、Letter 或自定义纸张、横竖方向、页边距、页眉页脚与页码。在页眉或页脚使用 `{page}` 插入当前页号。Ctrl+Enter 插入分页符。“视图”提供标尺、25–300% 缩放和适应宽度；Ctrl+鼠标滚轮也可缩放。状态栏显示页数、非空白字符数、词数和缩放比例；中文按汉字统计词数。

常用快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 / 保存 / 另存为 | Ctrl+N / O / S / Shift+S |
| 撤销 / 重做 | Ctrl+Z / Y |
| 剪切 / 复制 / 粘贴 / 仅粘贴文字 | Ctrl+X / C / V / Shift+V |
| 全选 / 查找 / 替换 / 下一个匹配 | Ctrl+A / F / H / F3 |
| 粗体 / 斜体 / 下划线 | Ctrl+B / I / U |
| 左对齐 / 居中 / 右对齐 / 两端对齐 | Ctrl+L / E / R / J |
| 分页符 | Ctrl+Enter |
| 文档开头 / 末尾 | Ctrl+Home / End |

文件菜单中的“示例文档”展示中文报告、标题和列表。功能区宽于窗口时可以横向滚动，窗口最小为 860×540。

## 文件格式

`.rword` 是完整保存文字、字符样式、段落、页面设置、标题和作者的原生格式。版本 1 使用小端二进制：16 字节头记录 `RWOR` 标识、版本、标志和负载长度；随后保存元信息、页面、样式表、带样式索引的 Unicode 字符及段落表。读取时校验版本、长度、Unicode 标量、索引、段落边界和数值范围，失败保留当前文档。

TXT 使用 UTF-8，接受可选 BOM，并规范化 CRLF/CR 换行；导出保留文字与分页控制字符，丢弃字体、段落和页面设置。HTML 支持格式化文字、标题、段落、列表、常见字体样式和预格式化文字等子集。脚本和外部资源不会执行或下载；链接地址、表格、图片等无法完整保存的内容会触发导入提示。导入后应保存为新的 `.rword`；导出使用另一个文件，避免覆盖导入来源。HTML 不是完整网页或 Microsoft Word 文件兼容格式。

每份文档最多 500,000 个 Unicode 标量、50,000 个段落、512 种字符样式；分页视图最多 4,096 页，单个外来文件最多 16 MiB。超过分页上限或行高无法容纳在页面时，会显示排版错误；可以撤销格式修改或调整页面设置。首版不提供 DOC/DOCX、表格、图片、宏、打印或 PDF 导出。

## 保存与恢复

保存先写同目录临时文件并同步，然后替换目标；目标被外部修改时，可以取消、另存副本或明确替换。每 60 秒为修改后的文档写独立恢复副本。下次无文件参数启动时，可以恢复、稍后处理或丢弃；其他活跃实例持锁的副本不会被接管。恢复后需要另存文档，恢复副本不代替正式保存。

恢复目录为 `$XDG_STATE_HOME/reliefword/recovery`；未设置时使用 `$HOME/.local/state/reliefword/recovery`。

## 开发验证

```sh
TMPDIR="$PWD/out/tmp" sh tests/build/test-reliefword.sh
TMPDIR="$PWD/out/tmp" make O=out/xorg-vmware-debug PROFILE=debug -j4 app-reliefword app-fileman nls
TMPDIR="$PWD/out/tmp" python3 tools/test_reliefword_qemu.py \
  --image /路径/已有Xorg镜像.raw --kernel /路径/kernel.sys \
  --output build/reliefword-dev/qemu-new --recovery
```

主机测试使用 ASan/UBSan 检查编辑、撤销后的保存状态、文件读写、异常输入、文件冲突、恢复锁、Unicode 定位和分页。QEMU 脚本使用既有 `test/test` 测试账户，克隆私有磁盘，校验注入文件哈希，驱动中文编辑、排版、导入导出、保存及撤销后新编辑的关闭提示，并独立回读保存结果。`--recovery` 还会等待真实的 60 秒定时保存，强制结束程序后恢复；输出目录必须尚不存在。不会修改源镜像或构建发布 ISO。首版实际运行结果与截图见 [验证记录](RELIEFWORD-VALIDATION.md)。VMware 验证未完成。
