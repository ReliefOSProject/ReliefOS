## 更新内容

### 办公、数学与任务管理

- 新增 **ReliefMath** 离线公式编辑器：一个 `.rmath` 文档管理多条 LaTeX 公式，提供源码高亮、括号匹配、补全、参数占位跳转、131 项插入目录，以及分数、根式、上下标、积分、矩阵、分段和对齐等工具与向导。支持公式排序、筛选、样式、模板、收藏、撤销重做及错误定位。
- ReliefMath 通过独立渲染进程显示预览，支持 SVG、透明 PNG、LaTeX 源码及批量导出；SVG 字形转为轮廓。后台文档读写包含原子保存、外部修改检测和恢复快照，接入锁定的 Cairo/FreeType 开发依赖及 STIX Two Math 字体和许可文件。渲染仅支持明确列出的数学子集，不提供完整 TeX 宏包环境。
- 新增 **ReliefTodo** 离线任务管理器：支持标题、备注、项目、标签、优先级、截止日期和完成状态，提供日期/项目/文本筛选、排序、多选、批量处理、统计和撤销重做。使用 `.rtodo` 原生文档，支持 CSV、Markdown 导出；文件工作进程处理冲突检测、保存锁、同步及原子替换。
- 新增 **ReliefMath++** 几何与函数工作区：支持二维显函数、隐式曲线、极坐标与参数曲线，三维显函数、参数曲面与空间曲线，以及点、线段、向量、圆、椭圆、平面、球、长方体等共 23 种对象。提供四个参数滑块、二维平移和三维旋转缩放、对象属性编辑、撤销重做与示例。
- ReliefMath++ 提供函数值、导数、积分、夹根、交点、极值、切线、曲面梯度/法向量、切平面、二重积分、曲面面积和几何/向量计算，支持 `.rmathpp` 文档、SVG/PNG 及值表 CSV。三维采用软件正交投影；计算使用数值方法，不是符号代数系统，也不要求 GPU 加速。
- 将已有 **ReliefMail** 邮件客户端实现接入主仓 FLTK 构建、默认组件及镜像，提供标准 desktop 启动入口，并加入 Office 分组。上一版仅交付其开发源码；本区间交付的是 SMTP/IMAP、多账户、邮件编辑与保险库等已有实现的默认系统集成。
- 三个新应用均接入默认菜单、独立图标、中文翻译、desktop/MIME 声明及原生文件打开关联。文件管理器增加 `.rmath`、`.rtodo`、`.rmathpp` 默认打开程序，同时保留用户自定义关联的优先级。
- Excel、Word、PPT 的“文件”按钮恢复 FLTK gtk+ 默认盒型；Office 顶栏统一使用“文件”，清理 `F` 助记标识及旧翻译，涵盖 Mail 主窗口和写信窗口。

### 图形桌面、账户与安装器

- 补入锁定的 Mesa Gallium DRI 子包，让桌面可使用上游 `vmwgfx` 入口；Xorg 从固定 fbdev 配置转为标准自动探测，在具备 DRM 能力时选择 modesetting/glamor，在没有 DRM 节点时保留 fbdev 路线。默认使用软件光标并关闭 modesetting page flip；这不等于关闭 DRI3/Present。
- XDM 会话环境允许传递 `RELIEFOS_XORG_EVENT_FD`；非 DRM 的 fbdev 启动包装器请求 32 位色深。更新 Xorg、SVGA3D 配置、软件回退及性能诊断文档。内核 DRM、SVGA3D 和信号实现见独立 ReliefNT Release。
- 默认账户资料增加 `video` 组（GID 44），安装账户及新建普通用户加入该组；统一账户名校验，拒绝 `root`、`nobody`、`wheel`、`video` 等保留名称，补充组成员和登录身份回归。
- 将 FLTK 应用清单集中到 `configs/fltk-apps.list`，同时供应用构建和安装器控制台目标裁剪使用。关闭 Xorg 时，安装载荷按同一清单裁剪图形应用，避免新增应用遗漏。

### 开发、构建与验证工具

- 为 ReliefMath、Todo、Math++ 增加组件配置、包归属、构建/资源 staging、文档格式与工作流测试；补充独立 QEMU GUI 验收工具、磁盘结果核对和原始运行截图记录。
- 主仓增加 DRM/execbuf/fence、fbdev、描述符与映射、用户异常、控制台恢复、调度和信号唤醒的用户态/宿主回归夹具，并同步 SDK 头文件导出清单。这些是主仓测试和集成更新，不作为内核实现重复列出。
- 内核版本回归脚本改为从版本配置读取字符串及数字字段，继续检查后缀、非法输入拒绝、无操作重建、父仓适配和 procfs，避免每次发布后留下旧版本断言。

## 破坏性更新

**是，主要涉及账户配置与交互工作流。**

- `video` 成为保留账户名和系统图形访问组；自定义账户库若已有同名账户、不同 GID 的 `video` 组，或 GID 44 被其他组占用，需要人工协调，不能直接覆盖账户文件。
- 图形默认配置不再强制固定 fbdev。自定义 Xorg 配置、设备访问权限及只适配旧固定路径的启动脚本需重新核对；新增用户入组不会自动修订所有已有系统账户。
- 顶栏移除 `F` 助记标签，依赖该标签自动提供的 `Alt+F` 入口的操作习惯或自动化脚本需调整；菜单项自己的 Ctrl 快捷键仍按各应用定义提供。
- 新文档使用各自原生格式，不承诺与 Microsoft Office 文件或其他数学/任务管理软件的私有格式兼容。内核 API 的迁移影响请另读 ReliefNT 5.1.1 说明。

## 更新与迁移注意事项

1. 先备份文档、邮件资料与保险库、账户组文件及自定义 Xorg 配置。现有安装跨版本原地升级、早期 Mail 开发资料迁移及全部文件系统组合尚未完成整版验收，先在独立副本验证自己的路径。
2. 从本标签递归初始化子模块，并使用该标签固定的 ReliefNT 提交；获取锁定依赖后重新构建。GitHub 自动源码归档不展开子模块，单独下载 ZIP/TAR.GZ 不能代替完整构建输入。
3. 合并 `video` 组配置并核对目标用户的补充组；已有会话需要重新登录才能重新取得组成员。保留用户个人配置，勿把示例账户文件直接覆盖到现有系统。
4. 按需合并 `/etc/X11/` 下的 Xorg/XDM 配置；是否得到加速上下文须结合设备能力、Xorg/Mesa 日志和实际绘制核实。软件回退、GPU 查询值或单个示例成功均不代表整版硬件加速验收。
5. 数学公式保存为 `.rmath`，几何场景保存为 `.rmathpp`，任务清单保存为 `.rtodo`。导出的图像、CSV、Markdown、LaTeX 用于交换，不保留全部原生编辑状态。
6. Todo 不提供自动保存、崩溃恢复、云同步或后台提醒；请主动保存。Todo/Math++ 的共享保存锁对不遵守协议的外部写入者不提供事务隔离；FAT32 空文件锁识别及 FAT32/exFAT 运行验证仍有限制。
7. **ReliefMath 在最近的 QEMU 标签检查中关窗触发段错误，退出码 139，尚未修复且原因未定位。** 本次版本发布没有修改其关闭逻辑，不应将该应用视为完整运行验收通过。

## 开发者提示

- 生产入口为根 GNU Make。数字基础版本为 `5.1.1`；主仓与固定的内核分别生成对应版本头，内核数字字段为 `5/1/1`，后缀继续通过 `EXTRAVERSION`/`LOCALVERSION` 配置。
- 本区间图形应用使用目标 musl、C++17、FLTK gtk+ 及中文字体；保持目标运行库边界。ReliefMath 还依赖锁定的 Cairo/FreeType 开发输入和随包数学字体，须通过现有构建链获取与装配。
- 新增图形应用时同步中央 FLTK 清单、组件、包归属、菜单、翻译及安装器控制台裁剪；新增公开头通过导出白名单供 SDK 消费。
- ReliefMath 支持范围见 [命令表](../RELIEFMATH_COMMANDS.md)；数值绘图、采样边界及任务保存限制分别见 [ReliefMath++](../RELIEFMATHPP.md)、[ReliefTodo](../RELIEFTODO.md)。
- 后续版本继续遵循[发布规范](../RELEASE_PROCESS.md)，从本次版本提交之后计算更新范围，两仓独立编写说明。

- **源码检查：**分别核对两仓 5.1.0 版本提交后的历史和最终差异；检查版本输入、系统身份、说明范围及提交文件。没有改写 ABI golden、音频 manifest 或任务外文件。
- **本次编译通过：**`TMPDIR="$PWD/out/tmp" make O=out/xorg-vmware-debug PROFILE=debug -j4 build-info kernel test-tools`；生成的主仓/内核版本均为 `5.1.1`、数字字段为 `5/1/1`。宿主普通及 ASan/UBSan 工具测试通过。
- **本次定向检查通过：**`test-version-abi.sh`、`test-kernel-version.sh`、`test-rpr-packages.sh`，均使用主仓 `out/tmp`；覆盖版本身份、后缀/数字字段、无操作生成、父仓适配、procfs 与 RPR 包命名/信任规则。
- **主仓完整门禁未通过：**本次 `make O=out/xorg-vmware-debug PROFILE=debug -j4 test` 在 `test-apk-ownership.sh` 停止，错误为 `component policy mismatch: ['soundctl']`。后续未执行项不计为通过；本次未改变该组件策略。
- **打包：**本次为源码发布，未重新打包最终 5.1.1 系统镜像、ISO、Installer ISO 或 SDK。区间内各应用已有编译、镜像成员核对记录，不能将旧产物重标为本版二进制。
- **QEMU：**区间内 Math++、Todo 等专题记录覆盖各自有限的操作、导出和磁盘结果检查；最近六个主窗口的“文件”标签检查使用基线私有副本注入新程序，Math 关窗退出 139。本次没有对最终 5.1.1 标签进行整版 QEMU 验收；Mail 写信窗口本轮标签修改仅做源码/编译检查。
