# ReliefOS 5.1.0

## 更新内容

### 桌面、登录与图形应用

- 引入 Xorg 桌面后端、锁定 Alpine Xorg/XDM 依赖闭包，先完成 TWM 会话，再迁移至当前 IceWM 桌面；增加后端选择、配置、会话生命周期诊断、异常退出恢复和 VT 契约探针。
- XDM 恢复标准配置文件和上游风格 greeter，整理服务器、会话与背景脚本；修复输入焦点和诊断事件读取，减少从登录到 IceWM 会话启动的等待。配置由独立签名包管理，避免改写上游 APK。
- IceWM 提供随包主题、背景、任务栏、快捷键和标准应用分类；恢复开始菜单分类生成，保持用户个人配置优先。默认终端由 xterm 切换为 st，提供 NEdit 文本编辑器和 Dillo 浏览器。PCManFM 曾试用后移除，不是本版交付组件。
- 12 个自有 X11 前端最终迁至 C++17 / FLTK 1.3.11：计算器、系统信息、文件管理器、任务管理器、扫雷、两款图片应用、画图、图片查看器、Doom launcher、Doom 平台前端和安装器。中间的 Motif 前端已被替代；第三方 NEdit 仍保留自身 Motif 依赖。
- 统一 FLTK 公共初始化、UTF-8 / gettext、中文字体、原生文件选择器翻译及目标 C++ 运行库；增加过长路径拒绝、外部文件名显示保护、焦点和文件操作回归。计算器提供整数表达式与错误检查；系统信息保留内核调试器入口；画图和查看器支持 BMP/PNG。
- Fileman 增加名称搜索和定位、地址与目录导航、多选、复制剪切粘贴、压缩解压和权限属性；重排工具区域与分栏。删除采用确认后的直接删除，没有回收站恢复。Task Manager 重排进程、性能和启动项页面；保留进程树、详情、终止确认及 CPU/内存/GPU 图表。
- 自有图形应用统一标准 hicolor 图标、桌面文件和文件打开关联；修复 Xorg 用户态适配中的 VMware 绝对鼠标坐标同步与 SVGA 配置问题。上述修复不等同于本版 VMware 完整验收。
- 修复第三方 GTK 程序的图片解码、图标主题及用户目录配置：补齐 glycin 图片/SVG loader、hicolor/Adwaita 图标主题及 GTK 默认主题设置，在会话客户端启动前创建 XDG 用户目录；增加 GTK 窗口与警告信息的运行检查工具。

### 办公与包管理

- 新增 **ReliefExcel**：多工作表、公式栏、相对/绝对及跨表引用、常用公式、样式、合并、填充、排序筛选、查找替换、冻结和缩放；支持原生 `.rexl`、UTF-8 CSV、模板、原子保存、外部修改检测和定时恢复。
- 新增 **ReliefWord**：中文分页编辑、字符与段落样式、列表、页面尺寸和页边距、页眉页脚页码、标尺、缩放、查找替换及撤销重做；支持原生 `.rword`、TXT/HTML 子集导入导出、原子保存、冲突检测和恢复。
- 新增 **ReliefPPT**：幻灯片版式、文字与嵌入图片、基础形状、多对象移动缩放/对齐/图层、背景和网格、演讲备注及全屏放映；支持原生 `.rppt`、PNG/离线 HTML 分享、原子保存、外部修改检测和恢复。
- 新增 **ReliefAPK**：通过真实 apk 命令浏览、搜索和查看软件包、依赖、文件与来源；支持安装、卸载、升级、重装、修复、本地 APK、操作队列和执行前模拟。提供软件源编辑与备份/冲突检测、缓存/密钥/审计等工具、设置和普通用户密码提权；后台子进程避免长操作阻塞主界面。
- 加入 **ReliefMail 开发源码**及模型/协议/存储/界面测试工具，包含 SMTP/IMAP、多账户、邮件编辑、附件与主密码保险库等实现。本提交范围结束时，尚未接入默认组件清单和主仓 FLTK 应用构建列表，不能视为默认镜像中已经可用的完整邮件客户端。

### 终端、工具与依赖

- 默认交互 shell 切换为官方 Alpine Bash，提供账户 shell 迁移辅助程序，保留 BusyBox ash 的 `/bin/sh`；交互 Bash 配置加入 fastfetch。
- 扩展 BusyBox 工具与包文件归属检查，用标准 ping 替代退役图形 Ping；移除旧 cmd 子模块和构建接线。引入 GNU coreutils 的 dd/yes，并补充管道、并发、错误路径和吞吐测量工具；这些是主仓工具及验证变化，内核管道实现见 ReliefNT Release。
- 新增 `driverinfo` 控制台工具，提供驱动状态与种类信息展示。
- mbedTLS 从 2.28.8 升至 3.6.7，调整配置、构建和目标 TLS 适配；保留证书和主机名校验，增加相关验证记录。

### 音频、安装与系统集成

- 增加 ALSA、ALSA 工具、Nuked OPL3、音频运行库、音量控制及音频服务的独立构建和 rootfs/SDK 集成；扩充音频设置与 Doom 输出、混音及音乐适配，归档主机和历史虚拟机证据。声卡与 PCM 内核实现属于 ReliefNT，不在此说明重复。
- 安装器从旧桌面协议转为当前 FLTK X11 前端，保留 TTY 安装路径；改进磁盘控制工具，移除主题选择步骤，提供是否安装 Xorg 桌面的选择，支持桌面和纯控制台目标配置。
- 系统镜像、GRUB、安装器和更新脚本改为直接装配/启动 `kernel.sys`，移除 `loader.elf` 及 `.drv` 产物的父仓接线、包装和启动路径；不再依赖旧 windowd 服务入口。Doom/launcher 不再进入默认镜像，仍可按组件选择构建。
- 增补启动控制台的 Linux TTY 用户态契约和 FD/VT/termios 回归，覆盖 OpenRC、PTY、evdev 与关闭标志相关场景；内核实现另见 ReliefNT Release。
- 根文件系统的 `VERSION_ID` 与本仓发布版本统一，避免继续报告历史 4.x 身份。

### 构建、测试与文档

- 增加 `make fetch-check` 对锁定依赖 URL 的探测，更新 sessreg 校验值、Xorg server 索引和 coreutils 下载镜像；FLTK 开发头/链接库由锁定且验证过的目标 APK 提供，避免引入宿主 glibc C++ 依赖。
- 修正 APK trigger 的 chroot 执行环境与 CI 非特权 userns 设置，强化签名、ownership、组件选择、目标依赖闭包、SDK、NLS 和桌面入口检查。
- 为内核目录重排同步主仓测试夹具/头文件路径，补充 OPOST、内存映射、vDSO、调度、事件唤醒、吞吐和控制台的用户态回归与分层证据；不把这些测试接线当作主仓实现了内核功能。
- 更新 Xorg、音频、FLTK、办公应用、ABI/系统调用和验证文档；Pages 避免链接未发布的内部文档。新增长期发布规范，固定版本提交区间、两仓职责、迁移说明与 GitHub CLI 发布流程。

## 破坏性更新

**是。** 本区间包含以下迁移影响，不能仅根据 `5.1.0` 的小版本形式判断兼容性：

- 桌面和安装器使用 Xorg/FLTK，旧 windowd 客户端、服务入口和专属配置不能直接作为新会话配置。XDM/IceWM 应使用各自标准配置路径。
- 镜像/启动集成删除独立 `loader.elf` 和 `.drv` 包装；自定义 GRUB、安装介质、更新脚本及产物收集清单必须同步，不能只替换一个旧启动文件。
- 登录 shell 改为真实 Bash，旧 Bash 路径别名和自定义账户 shell 设置应检查；`/bin/sh` 继续使用 ash，Bash 专有语法不能写入要求 POSIX sh 的脚本。
- Fileman 是直接删除模式，不提供回收站；文件打开关联和默认终端发生变化。默认镜像不再包含 Doom/launcher，PCManFM 也不随本版交付。
- mbedTLS 主版本升级涉及开发 API/配置差异；依赖旧 2.x 头文件或链接库的移植软件需要重建和适配。
- 新办公应用使用自身原生格式，并非 Microsoft Office 文件兼容替代。ReliefExcel 不支持 XLS/XLSX，ReliefWord 不支持 DOC/DOCX，ReliefPPT 不支持 PPT/PPTX；格式导出也不保证保留全部原生编辑信息。

## 更新与迁移注意事项

1. 本次只提供源码。备份用户文件、账户数据、软件源、world 约束、系统配置及自定义启动文件；使用对应标签和子模块提交构建，不能把旧本机镜像视为本版安装介质。
2. 现有安装的跨版本原地升级尚未完成整版验证。先在独立磁盘/虚拟机副本中验证自己的安装和升级流程；不要将历史局部成功理解为所有存量系统都能直接升级。
3. 切换桌面时核对 `/etc/X11/xdm/`、`/usr/lib/X11/xdm/` 和 IceWM 配置。用户个人主题/偏好优先于系统默认；纯控制台安装应检查所选 profile 的组件范围。
4. 官方 Bash 可用后再按需要使用 `/usr/lib/reliefos/migrate-shell`；检查账户 shell、登录脚本和 `/etc/shells`，保留有意使用其他 shell 的账户设置。
5. 自定义引导或打包流程应同时更新内核、GRUB 和 rootfs 的对应内容，移除对 `loader.elf`、`.drv`、旧桌面服务及旧包内容的假设。内核兼容性细节请另读对应 ReliefNT Release。
6. 办公文件先保留原件，并保存到对应 `.rexl`、`.rword`、`.rppt` 格式；CSV/TXT/HTML/PNG 是特定用途的交换或分享格式。文件管理器删除前应自行确认备份。
7. ReliefAPK 当前固定适配 apk-tools 3.0.8-r0；系统更新时保留软件源、信任密钥和本地配置。ReliefMail 尚需完成默认构建/镜像集成，不能作为升级后的默认邮件功能依赖。

## 开发者提示

- 主仓仅包含系统集成和用户态；递归初始化子模块，并使用本标签固定的内核 gitlink。不要将主仓 Release 正文当作内核更新清单。
- 生产入口为根 GNU Make；主仓与内核数字基础版本均为 `5.1.0`。内核 `EXTRAVERSION` / `LOCALVERSION` 继续独立工作，数字版本宏为 `5/1/0`。
- 自有图形前端使用目标 musl、C++17、FLTK 及锁定的目标运行库；保留 `-fno-exceptions -fno-rtti` 和现有 C 后端边界。新应用需分别处理组件、构建、镜像、菜单、关联、翻译与运行验证。
- 内核导出接口和相关夹具应消费正确子模块的头文件；不要修改 ABI golden 或音频 manifest 来掩盖不一致。性能脚本仅在声明的平台、场景和持久化语义内解释。
- 发布时遵循 [发布规范](../RELEASE_PROCESS.md)，下一版范围从本次 `5.1.0` 版本提交之后重新计算，仍分别编写两仓说明。
