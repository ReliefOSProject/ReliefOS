# 可选 VGA 文本控制台实施计划

用户已要求直接实现；实现阶段不提交、不推送、不新建分支。本次按用户后续的
“提交推送”授权只提交 VGA 功能、文档和验收脚本，保留上一任务 installer 的未提交修改。

**目标：** 仅显式 `console=vga` 时使用 VGA 80×25 文本终端替代 framebuffer TTY，保留六个 VT、ANSI 状态与 Xorg 往返切换。

**边界：** 不修改 framebuffer 的渲染、ANSI、模式设置实现。只在共享 console 分发入口增加独立分支；VGA 端保存硬件寄存器、字体及屏幕状态。拒绝不具备受支持 VGA 解码/图形恢复能力的设备，维持原后端。硬件不能表达的字体样式、任意像素、完整 CJK/Unicode 字库不模拟成图形。

- [x] 在 ReliefNT 新增纯字符终端、ANSI 解析器及 sanitizer 宿主测试：颜色、光标、滚动区域、插入删除、备用屏幕、UTF-8 降级、分片及畸形转义。
- [x] 新增 VGA 模式设置/字体/调色板/硬件光标与图形寄存器保存恢复模块，测试 I/O 次序和边界；不改已有 fallback VGA 行为。
- [x] 接入内核参数、启动日志、VT 输出/切换、80×25 winsize 和设备查询回复。验证默认关闭、后台输出隔离、六个终端独立状态及 panic。
- [x] 保持 VT_PROCESS/键盘/信号协议不变，运行 framebuffer console、panic、VT handoff、PTY 及新增测试，检查原 framebuffer 文件哈希未变。
- [x] 经根 Makefile 构建内核和 VMDK；使用最终镜像的专用磁盘副本和 GRUB 配置，在实际 QEMU 上验证参数开关、登录、真实 Vim、TTY1–6、XDM/IceWM 及反复往返。
- [x] 保存内核启动、TTY 登录、XDM、IceWM 四张真实截图；记录硬件/模式、实际验证范围和未支持项。VMware 验证未完成。
