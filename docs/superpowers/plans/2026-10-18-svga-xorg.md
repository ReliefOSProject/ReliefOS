# Xorg / VMware SVGA II 实现计划

> 使用 subagent-driven-development 逐模块执行与审查。用户已批准路线并要求开始；子代理统一使用 GPT-6-Luna / Max。当前工作树实施，不建分支、不提交、不推送。

**目标：** Xorg 通过符合 Linux ABI 的设备栈使用 VMware SVGA II，取得真实显示与硬件渲染证据。

**架构：** ReliefNT 提供 DRM/KMS 和匹配的 vmwgfx UAPI；底层复用并扩展 SVGA 资源管理。用户态使用上游 libdrm、Mesa SVGA 和匹配的 Xorg 驱动，保留 fbdev 恢复路径。

**技术栈：** C、Linux DRM UAPI、POSIX/Linux fd/mmap/poll、VMware SVGA II/3D、Mesa Gallium、Xorg、QEMU 与原生 VMware。

## 全局约束

- 仅在用户明确要求时提交、推送、建分支；当前无此授权。
- 不提交 out/、build/、.zcode/、result/、tools/dependencies.py 等产物。
- 不重生成 ABI golden，不改变既有音频事项。
- 上游 UAPI 的布局、编码、errno、能力与生命周期准确；不伪造未实现功能。
- GPU 提交必须验证资源归属、命令和范围，显示权限与渲染权限分开。
- 测试临时目录为 `$PWD/out/tmp`。编译、测试、运行分别报告；只报告有证据覆盖的平台与功能范围，不外推到未测试的平台或能力。
