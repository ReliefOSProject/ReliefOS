# ReliefExcel implementation plan

Approved in this conversation: C++17 + existing FLTK 1.3, modern Excel-like functional ribbon, Chinese UI/text, native .rexl + UTF-8 CSV, daily sheets up to 10,000 rows x 256 columns, 16 sheets, no charts/XLSX/macros/printing/network. Git delivery requires explicit user authorization. No kernel or theme changes. Existing unrelated untracked files stay untouched. All temporary artifacts use build/reliefexcel-dev and TMPDIR=out/tmp.

## Binding design
- File menu/quick actions, Home/Insert/Formulas/Data/View ribbon tabs, name box and formula input, visible-cell grid, sheet tabs, status aggregates. Real controls only; no in-client program title. Existing gtk+ FLTK scheme and SimSun/gettext support.
- Sparse workbook; cells contain raw UTF-8 input, literal flag, style, cached Value; stable sheet IDs. Interfaces in userland/apps/reliefexcel/{model,formula,document}.h. Core is independent from FLTK, no exceptions/RTTI/new runtime dependencies. Text refcounts immutable strings; Array uses explicit failure returns.
- Editing: selection, keyboard/IME-safe cell and formula editing, resize, clipboard TSV and internal styled/formula copy, fill handle, styles, merge/unmerge, row/column/sheet insert/delete/rename/reorder, sort/filter, find/replace, undo/redo. Commands are atomic; structural edits update references including absolute references. Deleted targets become #REF!. Copy/fill preserves $ and transforms relative references. Sort moves whole selected rows, translates moved formulas, leaves outside addresses unchanged. Filters hide rows, never delete content. Reject unsafe merged-boundary edits; merge nonempty data needs explicit discard confirmation.
- Formulas: + - * /, comparisons, & concatenation, grouping, ranges, cross-sheet refs, $ references; SUM AVERAGE MIN MAX COUNT COUNTA IF ROUND ABS COUNTIF SUMIF. IF short circuits. Memoized recalculation/cycle detection, real error values, no external refs or code execution. Quote-aware reference transforms. Supported function subset follows ordinary Excel semantics, not full Excel compatibility.
- Document: versioned length-prefixed UTF-8 .rexl, full round-trip of all content/styles/view settings. Load into temporary model then swap. Atomic save with file+directory sync and external stamp conflict check. Recovery copy every 60s, never overwrite user's file, restore/discard on next launch. CSV RFC4180 quotes/newlines, UTF-8 optional BOM, delimiter preview, preserve leading zero text; imports never activate formulas. CSV exports active sheet values and warns loss of native features.
- Limits: MaxCells=500000 per workbook; MaxTextBytes=32768 per input. Reject oversized/invalid input without changing current document. Initial defaults 1 sheet, 100% zoom, widths 104px, heights 26px. Long work uses Progress callbacks and cancellation; UI remains responsive and guards reentrancy.
- Integration: default xorg desktop app via components/build/ownership/.desktop/icon/localization; reliefexcel [path]; Fileman .rexl/.csv routing with explicit user associations respected. Console-only installer excludes app. No changes to XDM/IceWM themes.

## Tasks / owners
1. Model, atomic commands/history, sparse cell utilities, styles/filters/sort: core agent; tests host/test_reliefexcel_model.cpp. Own model.cpp/edit.cpp and tests only; shared headers coordinate with root.
2. Formula engine and reference rewriting: formula agent; formula.cpp and host/test_reliefexcel_formula.cpp.
3. Native/CSV I/O plus packaging integration: document agent; document.cpp and host/test_reliefexcel_document.cpp, integration manifests/build and fileman routing (not main ReliefExcel UI).
4. Root: FLTK main UI, edit/clipboard bridge, recovery, dialogs/ribbon/grid, common storage fixes, build/host runner, guest acceptance and screenshots.
5. Review all modules against spec, fix important findings, run source/build/model/I/O tests and actual private-image QEMU walkthrough. Keep original images unchanged; report build/test/runtime separately and mark VMware verification incomplete without real VMware testing.

Real GUI screenshots in QEMU: initial ribbon, Chinese ledger, formula/cross-sheet, sorting/filter, saved reopened workbook.
