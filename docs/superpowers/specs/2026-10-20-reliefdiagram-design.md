# ReliefDiagram 设计

## 目标与界面

提供原生 C++17 / FLTK 思维导图、流程图和逻辑关系图编辑器。沿用
ReliefOffice 的默认 gtk+ 控件、中文字体与“文件”菜单，不绘制应用主题。
顶端为菜单和分组工具，左侧为图形库及对象清单，中间为画布，右侧为属性，
底端显示操作提示、对象数和缩放。窗口缩小时重新分配画布空间。

## 编辑能力

- 思维导图：中心主题、子主题、同级主题、分支折叠、左右平衡自动布局。
- 图形：矩形、圆角矩形、菱形、椭圆、平行四边形、文档、数据库、便笺。
- 连线：直线、折线、曲线，标签、箭头、线宽与颜色；节点移动后自动更新端点。
- 选择、多选、框选、拖动、尺寸调整、内部复制粘贴、删除、撤销重做。
- 网格与吸附、平移、滚轮缩放、适合内容、键盘微调、对齐、等距分布和层级。
- 标签、备注、颜色、字体、尺寸与坐标属性；思维导图、审批流程、逻辑关系模板。

## 数据与边界

`.rdiagram` 使用 RDGM 文件头、版本 1、小端字段、载荷长度和 CRC32。
文档保存节点、父子关系、附加连线、样式及视图。最多 512 个节点、2048 条
附加连线、8 MiB；严格校验 UTF-8、唯一 ID、引用、父子循环和有限坐标。
一般连线允许回路，父子关系不允许循环。折叠只影响显示，不删除数据。
读取失败不替换现有文档；保存采用现有异步 IoJob、原子替换、外部修改检测，
拒绝符号链接。导出不能覆盖当前原生文档。

SVG 和 PNG 导出完整可见图形，包含文字、样式及箭头，不包含选择框或编辑网格。
支持 UTF-8 Markdown 大纲导出。首版不导入其他厂商格式，不提供联网协作。

## 结构和验证

模型与布局不依赖 FLTK；序列化独立于绘图。画布与 SVG 共用场景几何，
PNG 使用同一绘图路径。文件操作和 PNG 编码使用子进程，主循环轮询。
历史记录采用有界快照，拖动只产生一个撤销步骤。
