# ReliefMath 设计

状态：总体设计及本书面规格均已由用户确认，进入实施计划阶段；尚未开始实现。本文使用 2026-10-19 的主仓工作区，基线提交为 `372641705ae46f7523d26fef0e4e200212842c78`。没有获得提交、推送或新建分支授权。

## 目标与已确认选择

新增中文桌面数学公式编辑器 ReliefMath，沿用 ReliefExcel、ReliefWord 的 C++17、FLTK 1.3、系统默认 FLTK 主题与 Office 排版规范。用户确认首版定位为公式编辑器：一个文档管理多个公式，以 LaTeX 源码编辑、实时预览和工具辅助为中心；数学公式离线渲染，不要求完整 LaTeX 文档或宏包兼容；支持可继续编辑的原生文档、SVG、透明 PNG 和源码导出。

编辑方式为源码加工具。用户可以直接编辑 LaTeX，并用符号分类与搜索、命令补全、内置模板、用户收藏和结构向导插入表达式。向导为分子、分母、上下标、矩阵单元等位置生成可访问的占位点，支持在占位点间跳转。文档可新建、打开、保存、另存为，管理公式的增删、重命名、复制、调整顺序和导出。

第一版仅接受明确列出的数学语法，不执行任意 TeX 文档、宏包、外部文件、shell escape 或网络资源。公式内文字支持 Unicode，重点验证系统 SimSun 字体下的中文 `\text{}` 显示。界面中文和公式文字编码彼此独立。

## 界面与交互

窗口标题为 ReliefMath，不在内容区重复显示应用大标题。初始尺寸约 1180×780，最小尺寸约 960×600，并依据目标桌面工作区调整。顶部使用 ReliefExcel/ReliefWord 相同的文件菜单、快捷操作、选项卡和分组功能区；现有 `reliefos_fltk::init("reliefmath")` 提供 FLTK `gtk+` 默认方案与中文字体。使用真实标准 FLTK 控件，不更改全局主题、主题颜色、圆角或控件绘制方式。

主工作区从左到右由公式列表、LaTeX 编辑器和渲染预览组成。列表显示名称和渲染状态，并提供新增、复制、改名、删除和排序操作；列表上方可筛选文档公式及打开内置示例。源码区提供行号、语法高亮、括号匹配、命令补全、结构占位跳转、剪切复制粘贴、撤销重做、查找替换、全选和中文 IME 输入。源码与预览之间以及公式列表与编辑区之间可拖动调整宽度，可分别隐藏公式列表或预览。调整窗口后各区域保持可访问，不靠缩小字体压缩布局。

功能区包含“开始”“符号”“结构”“排版”“视图”：文件和编辑操作，希腊字母/关系/运算符/箭头/集合符号及搜索，公式模板和分数/根式/矩阵等向导，行间或行内样式/公式颜色/边距，以及预览缩放。所有控件均绑定实际操作，宽度不足时功能区可水平滚动。状态栏显示当前公式、文档公式数、UTF-8 字符数、渲染结果和缩放比例。对无效表达式保留最近一次成功预览，同时明确标为旧结果并显示可定位的解析错误。

## 公式工具与语法范围

插入工具按用途分组，支持搜索并插入希腊字母、常用数学符号、关系符、二元运算、箭头、集合、括号与间距命令。结构向导覆盖普通/显示分数、上下标、可选次数根号、自动伸缩括号、求和/乘积/积分/闭合积分、极限、常用三角与对数函数、矩阵与带括号矩阵、分段函数、多行和带对齐点的公式、向量/帽子/横线/绝对值/范数，以及 `\text`、`\mathrm`、`\mathbf`、`\mathit` 等数学字体。工具生成可编辑 LaTeX，不生成不可逆的专有表达式树。

渲染基线包括：数学分组、运算符间距和排版；`^` 与 `_`；`\frac`、`\mathrm` 等列明命令；`\sqrt` 及根指数；行内/显示样式；`\sum`、`\prod`、`\int`、`\iint`、`\iiint`、`\oint`、`\lim`；`\sin`、`\cos`、`\tan`、`\log`、`\ln`、`\exp`、`\min`、`\max`；矩阵、`cases`、对齐环境、`&` 和 `\\`；常见数学字母、希腊字母、数学字形和 `\text{}`。完整命令集由实现随文档提供的兼容清单定义；未支持的命令给出错误，不能被静默忽略。首版不声称实现完整 TeX/LaTeX，也不支持任意 `\newcommand`、`\def`、`\usepackage`、`\input`、任意环境或图形宏包。

## 技术路线与渲染边界

UI、公式列表、源文本、占位操作、原生文档读写和渲染任务协议独立于具体数学排版实现。较大的文档读写与批量导出同样在后台执行，以临时状态完成校验后提交；失败保留原状态，UI 显示进度并限制有冲突的操作。用 `Renderer` 边界封装解析、布局和矢量/栅格输出，渲染置于受限的独立 worker 进程，使用带版本、长度、请求 ID 与公式代次的非阻塞管道消息协议；不调用 shell 或通用 TeX 命令。源码编辑经短暂合并后排队渲染，旧代次响应丢弃，退出/切换文档时取消旧请求。对解析超时或 worker 崩溃提供状态、受控重启与安全失败，不阻塞 FLTK 主循环。

优先评估上游 MicroTeX 的固定版本 `0e3707f6dafebb121d98b53c64364d16fefe481d` 作为数学排版前端。该上游自述以 C++17 提供可嵌入数学公式渲染；其公开 Linux 图形后端采用 GTK/Cairo 组件，独立输出 SVG 的路径、字体映射、Unicode/中文回退及打包资源需要在 ReliefOS 目标上验证。ReliefOS 当前 C++ 目标全局使用 `-fno-exceptions -fno-rtti`，而候选源码包含异常处理及 `std::filesystem`。因此该候选不视为已确认可用依赖：先做隔离 worker 的主机与 ReliefOS 交叉编译、许可和字体/中文检查，再决定能否以适配层接入。不得借此把编译标志或主题行为扩大到其他应用。

渲染实现由一个明确、可审计的后端生成 SVG 与透明 PNG，共用同一数学布局与尺寸测量，避免预览与导出不一致。若候选库在目标交叉工具链、无完整 GTK 开发栈、进程隔离、CJK 字体或许可条件下不合适，保留 `Renderer` 接口，改用只覆盖上述公开语法的本地数学盒模型和绘图后端；不通过捆绑完整 TeX 发行版扩大系统镜像。后端决定和兼容清单要以真实编译及公式测试为依据。

候选上游：[MicroTeX 仓库与 README](https://github.com/NanoMichael/MicroTeX)，固定审查提交为上述 SHA。其代码许可证为 MIT，但资源目录另外包含多份字体许可证；实现必须审阅实际选用资源的授权、保留版权声明并随 ReliefOS 归档完整来源与许可文本，不因代码许可证推定全部字体可任意重分发。第三方资源是否纳入系统要在实施计划中列清单。

## 文档、保存与导出

`.rmath` 是有版本的原生格式，保存文档元信息、公式顺序、名称、源码和每个公式的字号/样式/颜色/留白选项。采用长度受限、明确版本的格式；公式稳定 ID 不依赖排序位置，撤销/重做保留名称、顺序、源码和设置。读取到临时对象、完成全文验证后再替换当前文档。损坏、截断、超长或未知版本不得覆盖当前状态。保存使用同目录独占临时文件、文件同步、原子替换和外部修改冲突检测；关闭未保存文档时提供保存、放弃和取消。每 60 秒为修改后的文档写独立恢复副本。恢复目录为 `$XDG_STATE_HOME/reliefmath/recovery`，未设置时使用 `$HOME/.local/state/reliefmath/recovery`，并使用实例锁；恢复内容不覆盖既有原文件。

导出命令作用于所选公式或全部公式，可输出独立 SVG、透明 PNG 和纯 LaTeX 源码；批量导出可由用户选择目录和文件命名规则。SVG 使用安全的 XML 输出，不保留脚本、外链、事件属性或注入标记；公式文本以 XML 安全编码输出。PNG 由同一渲染布局栅格化，背景透明，可设置缩放倍率与像素密度。SVG 的数学字形和中文文字转换为矢量轮廓，避免依赖接收端字体；不以嵌入位图冒充矢量公式。采用同目录临时文件并原子替换，拒绝路径穿越和意外覆盖，并对部分失败逐项报告；一个公式导出失败不能让其他结果显示为成功。复制源码和复制渲染图片为独立命令。导出绑定开始时的源码与设置快照，核对相应代次的成功渲染，不导出旧预览冒充当前结果。批量任务显示逐项进度，允许取消；取消保留已完成文件并列明未完成项，不删除原有文件。

首版资源边界：每文档最多 256 条公式；单条源码最多 64 KiB，文档最多 16 MiB；解析嵌套最多 128 层；一次预览或导出的尺寸最多 16,384 × 16,384 像素，栅格总像素最多 16,777,216；后台任务使用单公式请求并提供取消。接近或超过边界时说明具体限制，不静默截断或分配无界内存。这些值作为实现与验收上限；若目标验证要求调整，先修订规格并说明影响，不静默缩减功能。

## ReliefOS 集成

源码放在 `userland/apps/reliefmath/`，按 storage、model/document、snippet、renderer 协议、worker、视图和对话框分层。模型、序列化、源码补全和工具插入不依赖 FLTK，遵守 C++17、`-fno-exceptions -fno-rtti` 现行约束；若第三方 worker 需要独立编译配置，单独构建与打包，不改变 ReliefExcel、ReliefWord 或全局 C++ 标志。确认组件元数据、构建目标、Xorg 镜像 staging、标准应用菜单/办公分类、`.rmath` 打开关联、桌面文件、独立图标和中文翻译。控制台安装不携带该 GUI 应用。

不修改内核 ABI、全局 FLTK 主题、系统背景、音频 manifest、ABI golden 或 Office 其他应用。保留现有用户改动及无关未跟踪文件；所有构建临时数据使用仓库 `out/tmp`，截图写入新的、不会覆盖现有用户数据的结果目录。

## 设计自检

- 目标固定为受支持子集数学公式编辑与渲染，不把它描述成完整 TeX 文档编辑器。
- 候选 MicroTeX 的工具链、异常/RTTI、图形后端、中文字体、嵌入资源许可均列为进入实现前必须证明的事项。
- FLTK 默认外观限制与 Office 分栏布局均明确，未提出私有主题。
- SVG/PNG 的透明背景、内容安全、文件覆盖和错误边界均明确。
- 主机、编译、镜像、QEMU、VMware 验收层次分开，真实截图列为交付条件。
