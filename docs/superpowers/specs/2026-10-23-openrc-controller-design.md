# OpenRC Controller

原生 C++ / FLTK 系统管理应用，使用系统默认 gtk+ scheme、SimSun 和 系统中文翻译。
内容区不放应用名称横幅；工具栏、筛选器、可多选服务表格、详情与输出面板组成主窗口。
用户已要求直接执行，不增加设计或计划批准环节。

## 功能

- 实际 OpenRC 服务清单、状态、运行时间、运行级别；搜索、状态及运行级别筛选。
- 启动、停止、重启、重载、条件操作、模拟执行、zap 与脚本自定义命令；批量串行操作，失败停止。
- 描述、脚本、正反向依赖、运行级别成员及堆叠、创建/删除空的自定义运行级别、切换普通运行级别。
- 服务 conf.d 与全局 rc.conf 编辑、冲突检测、原子保存、同步与备份恢复。
- 原生状态诊断、崩溃/监督/手动/未分配服务清单、依赖缓存重建、日志与诊断报告导出。
- 自动刷新、实时命令输出、取消与超时、快捷键、桌面入口和系统图标。

## 授权与执行

root 账户直接进入。普通用户进入前选择 sudo 当前用户密码或 root 密码，经固定路径 worker
完成认证；GUI 不提权，保持一个受限 root 会话。取消认证退出，失败可重试。
密码字段禁止输入法，密码仅经过 stdin/控制终端，使用后清零，不写日志、参数、环境或磁盘。
worker 验证每个请求，只构造固定 OpenRC 可执行文件与独立 argv，不使用 shell 字符串。
协议带长度限制，正确处理短读写。界面异步收发，worker 持续排空输出并限制内存。
关闭会话时终止和回收当前操作；取消操作可能留下 OpenRC 过渡状态，界面明确提供状态诊断与 zap。
不直接调用 shutdown/reboot/sysinit 等特殊运行级别；一般运行级别切换需确认。
