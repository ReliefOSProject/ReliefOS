# ReliefPPT 首版设计

用户于 2026-10-17 确认以下范围并要求“可以，开始吧”。采用与 ReliefExcel / ReliefWord 相同的 C++17、FLTK 1.3、系统主题和中文支持；完成实现、测试、系统内实际运行及截图。不自动提交、推送或建立分支。

## 用户体验

紧凑文件菜单和开始/插入/设计/放映功能区，左侧可滚动幻灯片缩略图，中间灰色工作区与幻灯片画布，下方可收起备注和状态栏。不在客户区重复放程序大标题，不放无法使用的占位按钮。默认 1180×760，最小 900×600，功能区过宽可水平滚动。

新建、复制、删除、上下移动幻灯片；空白、标题、标题与内容、双栏四种布局，默认 960×540（16:9），可整体切换为 960×720（4:3）并按比例变换已有对象。背景颜色、三种配色模板。备注保存在原生文件中，放映不显示备注。

对象有文字框、矩形、椭圆、直线、箭头和图片。鼠标选中/Shift 多选、拖动、八个缩放手柄，Shift 保持比例；键盘方向键移动，Shift 加大步长，Delete 删除，Ctrl+D 复制。多选对齐到左/中/右/上/中/下、置顶置底/上移下移。对象坐标始终落在幻灯片内，缩放至少 4×4。提供网格、吸附、25–200% 缩放和适合窗口。

双击文字框使用原生 FLTK 多行输入编辑，支持 Xorg 输入法、UTF-8 剪贴板与中文显示；文本样式按整个文字框设置，包含字体族、6–144 磅、粗体/斜体/下划线、颜色、左/中/右对齐、项目符号。文字自动换行；过长内容在框内裁剪且属性栏明确提示，避免自动缩小后难读。Esc 提交文字并返回画布，窗口关闭/切页/保存前先提交编辑；撤销与重做作用于完整的编辑操作。图片支持 PNG/BMP（可扩展到系统现有解码器支持的格式），嵌入文件、不依赖来源路径；保留透明度，默认等比适合插入尺寸。

F5 从第一张放映，Shift+F5 从当前张放映。全屏黑色边框、按比例居中，左右/PgUp/PgDn/空格翻页、Home/End 跳转、B 黑屏、Esc 退出；最后一张之后显示结束页，上一页可回最后一张。编辑器和放映共用渲染器，实际内容一致。

## 数据和文件

命名空间 rp，核心不依赖 FLTK，无异常和 RTTI。Deck 含幻灯片、嵌入 RGBA 图片、元信息、页面尺寸、修订号；每个 Slide 含背景、备注及从底到顶排序的对象。对象 ID 在同一 Deck 唯一；文本 UTF-8、样式按对象保存。几何均为有限浮点数。每次修改构造候选 Deck，通过完整校验后一次提交；历史同时记录当前页和对象选择，最多 64 个历史状态，合理限制内存。修订号采用独立单调高水位，避免撤销后新分支被误判已保存。只读选择/缩放不算文档修改。

限制：最多 500 张幻灯片，每张 256 对象、全文共 20,000 对象；单个文字框最多 32 KiB、单张备注 64 KiB；所有图片共 64 MiB RGBA，每张不超过 4096×4096；原生文件最多 96 MiB，最多 256 张图片。新文档至少一张幻灯片，删除最后一张产生空白页。

原生 .rppt 使用 RPPT 魔数、版本 1、显式小端字段和长度，保存完整对象、图层、样式、背景、备注及嵌入图片。读取先完整校验到临时 Deck，失败不改变当前文档。校验截断、未知版本/枚举、非 UTF-8、NaN/Inf、重复 ID、非法图片索引、溢出和过限输入。

PNG 导出当前幻灯片，使用与编辑和放映相同的渲染器，以原始 960 像素宽度导出。离线 HTML 导出整个演示文稿，每张为嵌入的 PNG，附固定键盘导航和页码；无外部依赖，不导出备注，不导入任意网页或运行外部脚本。导出不改变当前文件与保存状态；默认文件名与 .rppt 不同，禁止覆盖当前原生文件（包括同 inode 的路径）。首版不提供 PPT/PPTX、音视频、复杂动画、旋转、分组、表格、图表、打印或 PDF。

保存采用同目录独占临时文件、fsync、原子替换、父目录同步，并检测外部修改；取消及提交前失败保留原内容。冲突检测是乐观检查，最后检查到提交之间仍可能与非合作写者竞争。提交后同步失败时尝试回滚；若底层同时拒绝回滚，明确报告目标可能已变化并给出保留的旧文件备份位置，不能承诺持续 I/O 故障下目标一定不变。每 60 秒写独立私有恢复文件，sidecar flock 避免另一活跃实例被接管；恢复后另存。关闭/新建/打开/示例前提示保存，选择取消保留编辑。所有路径操作检查分配失败与长度。

## 集成和验收

默认 Xorg 办公组件与 .desktop（Office;Presentation;）、专用图标（BMP+hicolor 六尺寸 PNG）、窗口 WM_CLASS/_NET_WM_ICON、简体中文翻译和 Fileman .rppt 关联。控制台安装排除程序及图标。不改内核、ABI golden、音频声明、XDM/IceWM 主题或背景。保留既有无关未跟踪文件。

临时产物仅 build/reliefppt-dev，TMPDIR=out/tmp。主机 ASan/UBSan 验证模型、几何、格式、文件冲突和恢复；目标 ELF 编译；QEMU 使用既有 Xorg 磁盘的私有克隆，记录注入文件哈希，不改变源镜像。实测中文、移动缩放、多页操作、保存重开、PNG/HTML 导出、全屏翻页及真实定时恢复，并从 VM 外独立解析保存内容。交付真实界面和放映截图，编译/测试/运行分开报告，始终标明“VMware 验证未完成”。
