职责与修改
==========

先阅读根 AGENT.md、真实源码、构建图和工作树。保留已有用户修改，
避免未授权提交、推送、分支和进程操作。自研源码登记到所属 Kbuild，
不恢复平行编译链。内核工作在 ReliefNT 子仓完成，主仓只记录其 gitlink。
文档修改也必须核对实际接口、命令、路径和失败边界。

代码与接口
==========

函数注释说明职责、参数所有权、可空性、容量、锁与执行上下文，返回值
包含错误及特殊状态。保留项目已有 Doxygen 约定；采用 RST 手册不要求批量改写
代码注释。私有实现不作为公共 UAPI，跨层变化同步实现、头导出和真实消费者。
不要以增加 sleep、吞错误或关闭验证替代根因修复。

安全与问题报告
==============

TLS、认证和存储错误保留阶段、返回码与设备/构建身份，不记录密码、令牌、
Cookie、私钥或请求体。问题报告注明版本/提交、平台、命令、配置和复现步骤。
安全报告区分静态观察与实际运行证据，不虚构修复版本或验证结果。
