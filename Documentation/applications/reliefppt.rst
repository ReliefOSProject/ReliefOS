=========
ReliefPPT
=========

ReliefPPT 是 ReliefOS 内置的 C++ / FLTK 演示文稿编辑器。界面沿用系统原生控件和主题，支持中文显示、Xorg 输入法和 UTF-8 剪贴板。通过应用菜单启动，或运行 ``reliefppt [演示文稿.rppt]``；Fileman 可直接打开 ``.rppt`` 文件。

开始制作
========

左侧选择幻灯片，中间编辑内容，顶部通过“开始、插入、设计、放映”切换工具。文件菜单提供新建、打开、保存、导出及三页示例。常用操作也提供工具提示。

1. 在“开始”选择版式，再点“新建幻灯片”。支持空白、标题、标题和内容、两栏内容；也可以复制、删除或在“设计”中上下移动整张幻灯片。最后一张删除后保留一张空白页。
2. 插入文本框、图片、矩形、椭圆、直线或箭头。单击选择，按住 Shift 单击多选；拖动对象移动，拖动八个控制点缩放，按住 Shift 保持宽高比。方向键微调，Shift 配合方向键每次移动 10 单位。
3. 双击文本框或按 F2 / Enter 编辑，Esc 完成编辑。字体、字号、粗体、斜体、下划线、文字颜色、对齐和项目符号作用于整个文本框。文字自动换行；超出边界的部分裁剪，属性对话框提示增大文本框或减小字号。
4. “位置与大小”可以精确调整几何、边框和填充。“插入”还提供多对象对齐和图层顺序。“设计”可选择 16:9 / 4:3、当前页配色、背景和网格；吸附移动时按住 Alt 可临时取消吸附。
5. “放映”可调整缩放、适应窗口或打开演讲备注。备注随原生文档保存，不进入放映、PNG 和 HTML。

图片支持 PNG 和未压缩的 24/32 位 BMP，插入时嵌入 RGBA 数据，之后移动或删除源图片不影响演示。PNG 保留透明度；BI_RGB BMP 的保留 alpha 通道按不透明处理。直线和箭头为水平线段，箭头指向右侧；首版没有旋转、对象组合或斜线端点编辑。

保存、分享与恢复
================

``.rppt`` 是可继续编辑的原生格式，保存幻灯片、对象、图层、样式、背景、备注和图片。首版不读写 Microsoft PPT / PPTX。保存采用同目录临时文件及原子替换；检测到文件被其他程序修改时，会提示另存副本或明确替换。该检测为乐观检查，不能排除其他写者在最后检查后立即修改文件。提交后同步失败会尝试回滚；如果磁盘同时拒绝回滚，会明确报错并提示保留下来的旧文件备份位置。

PNG 导出当前幻灯片，尺寸与幻灯片单位一致，默认宽屏为 960 × 540。HTML 导出整个演示，每页为内嵌 PNG，带浏览器键盘导航和全屏按钮，可离线打开；这是分享格式，不能重新导入编辑，也不包含备注。导出保留当前编辑文档，并防止覆盖已打开的原生文件。

有未保存修改时每 60 秒保存恢复副本，包括尚未退出文本框或备注输入框的内容。副本位于 ``$XDG_STATE_HOME/reliefppt/recovery``，未设置时使用 ``$HOME/.local/state/reliefppt/recovery``。正常保存或明确丢弃会清理本窗口的副本；意外结束后再次启动可选择恢复为新文件。恢复时优先使用最新的有效副本，跳过损坏或仍被其他实例占用的文件；恢复后继续编辑时，仅在下一份自动保存成功后清理上一代副本。同一时间运行的窗口通过锁避免抢占对方副本。

快捷键
======

* 快捷键：Ctrl+N / Ctrl+O; 操作：新建 / 打开

* 快捷键：Ctrl+S / Ctrl+Shift+S; 操作：保存 / 另存为

* 快捷键：Ctrl+Z / Ctrl+Y、Ctrl+Shift+Z; 操作：撤销 / 重做

* 快捷键：Ctrl+C / Ctrl+X / Ctrl+V; 操作：复制 / 剪切 / 粘贴对象或文字

* 快捷键：Ctrl+A / Ctrl+D; 操作：全选对象 / 创建对象副本

* 快捷键：Ctrl+M; 操作：按所选版式新建幻灯片

* 快捷键：Ctrl+B / Ctrl+I / Ctrl+U; 操作：整个文本框的粗体 / 斜体 / 下划线

* 快捷键：F2、Enter / Esc; 操作：编辑所选文本框 / 完成编辑

* 快捷键：Delete; 操作：删除所选对象

* 快捷键：Ctrl+鼠标滚轮; 操作：调整画布缩放

* 快捷键：F5 / Shift+F5; 操作：从头放映 / 从当前页放映

* 快捷键：放映中方向键、PageUp / PageDown、空格; 操作：切换幻灯片

* 快捷键：放映中 Home / End、B、Esc; 操作：首张 / 末张、黑屏、返回编辑

输入框获得焦点时，选择、剪贴板和文字撤销遵循 FLTK 输入控件的行为。

资源范围
========

上限为 500 张幻灯片、每页 256 个对象、总计 20,000 个对象、256 张内嵌图片。单张图片最大 4096 × 4096，全部 RGBA 最多 64 MiB；每个文本框最多 32 KiB UTF-8，单页备注最多 64 KiB；原生文件最大 96 MiB。文字字号 6–144 磅，页面尺寸 240–4000 单位；对象必须完整位于页面内。

撤销最多保留 64 个状态，元数据预算 64 MiB；不可变图片像素在状态之间共享，删除图片或幻灯片会回收当前文档不再使用的图片槽位。文本换行保护常见中文、组合字符和 emoji 序列，不是完整 Unicode grapheme-break 实现。首版没有音视频、动画、表格、图表、打印或 PDF 导出。
