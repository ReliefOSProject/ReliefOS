===========
ReliefExcel
===========

ReliefExcel 是 ReliefOS Xorg 桌面内置的 C++17 / FLTK 表格程序。可以从开始菜单启动，也可以运行 ``reliefexcel [文件.rexl | 数据.csv]``。Fileman 默认使用它打开 ``.rexl`` 和 ``.csv``；用户自己设置的文件关联优先。

日常使用
========

- 在单元格输入文字、数字或以 ``=`` 开头的公式；双击或 F2 编辑，Enter 确认，Esc 取消。上方名称框可跳转到 ``C25`` 等地址，公式栏可查看、编辑完整内容。
- “开始”提供剪贴板、字体、颜色、对齐、边框、合并和数字格式。选择区域后可向下/向右填充，也可拖动选区右下角的填充柄。
- “插入”管理行、列和工作表；底部标签切换工作表。“公式”提供自动求和、函数说明和显示公式。
- “数据”提供排序、筛选、查找替换和 CSV 导入导出。只选中一个单元格时，排序/筛选采用当前已使用区域；明确选择矩形时，排序只移动该矩形中的数据。筛选隐藏行而不删除数据。
- “查看”提供冻结首行、首列、网格线和缩放。拖动行列标题边缘可以调整尺寸。
- Ctrl+S 保存、Ctrl+O 打开、Ctrl+Z 撤销、Ctrl+Y 重做；Ctrl+C/X/V 复制/剪切/粘贴，Ctrl+Shift+V 仅粘贴值，Ctrl+F/H 查找/替换。Ctrl+鼠标滚轮缩放。
- 文件菜单中的“记账模板”包含中文账目和跨工作表汇总，可作为入门示例。

文件与公式
==========

``.rexl`` 保存整个工作簿的输入、公式、样式、合并、筛选和视图设置。CSV 使用 UTF-8，支持引号、字段内换行和 BOM；导入前可预览并选择逗号、分号或制表符。导入保留前导零，形似公式的外来文本不会自动执行。CSV 导出仅包含当前工作表的计算值；需要保留公式和样式时请保存 ``.rexl``。

公式支持算术、比较、``&`` 文本连接、括号、区域、``$`` 绝对引用和带引号的跨工作表引用，例如 ``=SUM('记账明细'!E2:E9)``。支持 ``SUM``、``AVERAGE``、``MIN``、``MAX``、``COUNT``、``COUNTA``、``IF``、``ROUND``、``ABS``、``COUNTIF``、``SUMIF``。``IF`` 只计算选中的分支；除零、循环和失效引用会显示错误值。函数集合是常用子集，不提供完整 Excel 文件或函数兼容性。

剪切移动会让指向被移动单元格的引用跟随目标位置；跨工作表移动时，公式仍保留对原工作表其他单元格的引用。若只移动某个被引用区域的一部分，无法表示为单个连续区域时会拒绝整个移动，原数据保持完整。复制和填充则按 ``$`` 标记调整相对引用。

每个工作表最多 10,000 行、256 列；每个工作簿最多 16 个工作表、500,000 个有内容或样式的单元格；单个输入最多 32 KiB。支持中文显示及 UTF-8 输入/剪贴板；输入法由 Xorg 会话提供。不支持 XLS/XLSX、图表、宏、透视表或打印。

保存与恢复
==========

保存先写同目录临时文件，完成同步后再替换目标。目标被其他程序修改时会提示，允许另存为或明确替换。在替换前取消或失败，会保留原文件。每 60 秒为已修改的工作簿写入独立恢复副本，下次启动可恢复、稍后处理或丢弃；仍由其他 ReliefExcel 窗口使用的副本不会列入恢复提示。恢复副本不是正式保存的替代品。
