=============
ReliefDiagram
=============

ReliefDiagram 是 ReliefOffice 中的原生思维导图、流程图和逻辑关系图编辑器。
使用 C++17、FLTK 默认 gtk+ 控件和系统中文字体，启动命令为
``reliefdiagram [文档.rdiagram]``。系统菜单位于 Office applications 分组，
也提供标准 desktop、应用图标、MIME 和文件管理器默认打开关联。

编写与排版
==========

默认示例是项目规划导图；“模板与文档”提供项目规划、审批流程和系统逻辑关系。
“文件 → 新建空白图”创建空文档。新模板会先处理当前文档的未保存修改。

从图形库双击，或使用“开始与插入”工具添加矩形、圆角矩形、判断菱形、
终止椭圆、输入输出、文档、数据库和便笺。选中主题后用 Tab 添加子主题，
Enter 添加同级主题；“折叠或展开”只隐藏后代，保留所有文字、备注及关系。

连接工具依次点击两个图形，创建附加连线。右侧可设置直线、折线或曲线，
标签、颜色、线宽和无箭头、终点箭头或双向箭头。父子分支自动绘制；
逻辑连线独立存在，可以形成回路，但不支持同一图形到自身的连线。

画布交互：

- 单击选择，Shift 单击多选，在空白处拖动框选。
- 拖动图形移动；移动父主题时带上整个分支。右下角手柄调整图形尺寸。
- 中键、右键或平移工具拖动画布，滚轮以指针位置为中心缩放，Home 适合内容。
- 方向键微调 1 个单位，Shift+方向键移动 20 个单位；网格吸附可独立开关。
- 双击或 F2 编辑文字；右侧可输入多行文字、备注、颜色、字号、坐标和尺寸。
  修改后点击固定的“应用属性”按钮或按 Ctrl+Enter。多选时样式作用于同类对象，
  文字、备注和位置只修改首个对象。
- “布局与排列”提供左右平衡思维导图、向右树形、流程分层、对齐、等距分布
  和置顶置底。流程分层保留回路，不做避障布线，复杂图可手动排布。
- Ctrl+C/V 使用应用内部图形剪贴板，包含选中主题的后代与内部连线；Ctrl+D 创建副本。
  Delete 删除选中对象及其后代和相关连线；Ctrl+Z/Y 撤销重做。

文件与导出
==========

Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+O 打开。磁盘读写与原子保存由后台
子进程处理；保存检测外部修改、拒绝符号链接，并在失败时保留当前文档。
保存之后继续新建、打开或退出的操作，会等待保存成功再进行。

- ``.rdiagram``：可继续编辑的完整文档，保留折叠分支、备注、样式及视图。
- SVG：完整展开内容的矢量图，文字保持 UTF-8，可继续在矢量工具中处理。
- PNG：白色背景，完整展开内容，图形主体最长边不超过 2000 像素，外围留白 24 像素。
  图像使用与画布相同的场景绘制，压缩编码在后台子进程进行。
- Markdown：包含所有主题（包括折叠分支）、备注和附加连线的 UTF-8 大纲。

图片不包含编辑网格、选择框或工具栏。导出禁止覆盖当前原生文档，也会处理
目标文件覆盖确认及写入冲突。SVG 在其他系统上的字形取决于可用字体。

格式与限制
==========

最多 512 个图形、2048 条附加连线，原生文档与单次导出上限 8 MiB。
文字最多 4096 字节、备注 16384 字节、连线标签 1024 字节；长标签受图形尺寸
限制，画布会换行或省略，完整内容仍保存在文档和大纲。连线标签最多显示
60 个字符。坐标范围 ±100000，图形宽度 40–2000、高度 28–2000，字号 10–48。
历史保留最近 32 次修改；一次拖动是一个撤销步骤。

RDGM 版本 1 使用 16 字节文件头：魔数 ``RDGM``、32 位小端版本号、32 位载荷
长度、32 位 CRC32。载荷保存标题、单调对象 ID、视图、节点和连线。
解码会校验 UTF-8、唯一 ID、引用、父子循环、有限数值和容量限制，失败不替换
当前文档。首版不导入其他厂商格式，也不提供联网协作。
