==============
版本与发布记录
==============

当前版本来自 ``configs/build-version``。本目录归档 ReliefOS 自身的发布说明；
原始正文、标签和源码保存在 `GitHub Releases <https://github.com/ReliefOSProject/ReliefOS/releases>`_。

历史说明保留发布时的功能范围、迁移要求、验证结果与已知限制，不代表当前
版本状态。旧文档链接固定到对应发布标签，历史命令和路径不作为现行使用指南。
新版本按 :doc:`../process/releasing` 归档。
