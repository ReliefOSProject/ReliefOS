==============
ReliefOS 5.3.0
==============

更新内容
========

- 新增 C++/FLTK **OpenRC Controller**，支持服务查询与批量操作、依赖和运行级别管理、配置编辑、备份恢复及日志导出。长操作异步执行，图形界面保持普通用户身份，由认证后的受限工作进程执行管理请求。
- 新增 C++/FLTK **Network Controller**，提供接口查询、DHCP/静态 IPv4/禁用配置、DNS 策略、连接诊断及配置恢复；沿用 OpenRC 网络服务和统一解析器发布流程。
- 集成 ReliefNT 原生 **.ko** 的配置、安装、依赖与别名数据库、模块自动加载和薄 initramfs。默认配置仍将生产组件内置，可选择支持独立生命周期的部件为模块；镜像检查根设备与文件系统依赖闭包，不静默改写内核配置。
- 内核更新按版本发布成对的内核、initramfs、模块及 ABI 清单，增加 A/B 引导选择、摘要核对和回退。签名 APK、安装器及恢复流程使用同一配套关系。
- 新安装可选择创建并配置 **/swapfile**，提供容量预检、完整分配、0600 权限、fstab/OpenRC 集成和启动后激活检查。默认不创建；更新已有系统保留原有 swap 设置。
- 增加 **IPv6 RDNSS** 守护进程与 OpenRC 服务，按路由器通告有效期维护 DNS，通过统一发布器与 DHCP DNS 合并；显式 DNS 策略优先。配套用户态接口、头导出和双栈测试同步更新。
- 接入 USB 2.0/3.x 存储及键鼠的系统配置、模块化启动和验证工具，并提供设备移除、只读介质与实际运行边界说明；驱动实现归属 ReliefNT。
- 完整打包 GNU coreutils 9.12 的 **109 个命令入口**，核对文件及 APK 所有权并保留旧命令路径；BusyBox 继续提供启动、救援和其余命令。
- 为 Dillo 配置不依赖界面语言的中文字体回退和用户配置初始化；恢复终端上游默认颜色，调整桌面及安装器入口，移除已退休桌面的快捷方式。
- 移除旧 ReliefOS Desktop/windowd、自研图形 UI 与相关配置和库导出，统一现行 X11/FLTK 路径。整理 Kconfig，主仓只配置产品和应用，内核配置由 ReliefNT 独立维护。
- 文档迁移至 **Documentation/** 的 Sphinx/reStructuredText 手册，更新 RPR 文档集成并归档历史 Release；测试按实现归属分仓，增加模块启动、USB、内存压力与桌面延迟的系统验证工具，修复 APK/音频测试的宿主环境适配。

破坏性更新
==========

**是，涉及已退休图形接口、命令提供者、配置与开发路径。**

- 旧 Desktop/windowd、鼠标区域和自研 UI 导出不再提供；依赖这些接口的程序须迁移到现行 X11/FLTK 及公开头文件并重新构建。
- 同名常用命令由 GNU coreutils 提供，选项和输出可能与 BusyBox 不同。APK 正常事务转移文件所有权；自定义脚本需核对实现，救援调用可显式使用 /bin/busybox。
- 内核、initramfs 与模块必须作为匹配的版本集合更新；旧 .ko 和 Linux 原版二进制 .ko 不能直接混用。更新选择器时需同时安装配套 BIOS/EFI GRUB 模块。
- 旧文档和已删除的配置路径不再作为开发入口；使用 Documentation/、当前组件清单和 Kbuild/Kconfig 目标。

更新与迁移注意事项
==================

1. 本次为 **正式源码 Release**，提供标签及 GitHub 自动源码归档，不附预编译 VMDK、ISO、Installer、SDK 或 APK。使用 Git 递归初始化标签固定的子模块；GitHub ZIP/TAR.GZ 不展开子模块。
2. 更新前备份用户资料、受保护配置和引导分区。使用新的 O 目录重建；沿用配置时执行 olddefconfig，显式检查内核的 y/m/n 选择。ReliefOS defconfig 同时重置对应的 ReliefNT 配置，普通构建保留已有内核设置。
3. 模块安装于 /lib/modules/<uname -r>/。保留对应恢复版本的内核、initramfs 和模块；不要只复制单个内核文件或将卸载忙碌设备失败视为异常。
4. 自动 swap 只在全新安装时可选，当前要求支持的 AHCI SATA 后端及启用 swap 的配套内核；NVMe、USB 等后端尚不支持。已有系统不会被自动增添 swap，启用后应检查 /proc/swaps。
5. 网络控制器的持久化编辑仍限于已支持的 IPv4 配置；IPv6 由 SLAAC 和标准命令管理，RDNSS 提供自动 DNS，没有有状态 DHCPv6 地址租约或 DNSSL 自动配置。保存并应用网络配置可能中断连接。
6. 本次发布核对版本生成、数字宏和严格文档构建，不重新构建或提供系统镜像。历史单项 QEMU 结果不等于本标签整版复验；**VMware 验证未完成**，物理硬件未验证。桌面编译压力延迟、ReliefMath 关窗故障和完整本机自举仍有未完成项。

开发者提示
==========

- 基础版本为 **5.3.0**，主仓生成数字字段为 **5/3/0**，/etc/os-release 的 VERSION_ID 同步为 5.3.0；内核版本与模块 ABI 身份由 ReliefNT 自身生成。
- 使用根 Make 入口及各目录 Kbuild；第三方保留原生构建系统。内核机制、UAPI 与内核测试在 ReliefNT，系统应用、打包和完整虚拟机编排在 ReliefOS。
- 驱动服务表使用版本 2，旧版本描述符会在初始化前拒绝。历史 ABI golden 保留，不能从前缀兼容或定向测试通过推导旧驱动二进制兼容或完整 Linux/POSIX 认证。
- 本说明覆盖主仓 5.1.2 版本提交 **5d844df1a0520c473139737b82a7d810723d4fef** 之后至本标签的有效更新，排除内核实现及纯 gitlink 更新；下一版以本次版本提交为起点。
