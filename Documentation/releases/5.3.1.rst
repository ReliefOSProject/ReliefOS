==============
ReliefOS 5.3.1
==============

更新内容
========

- Fileman 接入 inotify 自动刷新当前目录，合并短时间内的变更并保留仍存在的选中项，尽量保留滚动、键盘焦点和正在编辑的地址；同步已展开的当前目录树，监视不可用时提示并可通过 F5 重新扫描和恢复监听。

- 安装器将 BIOS/UEFI 引导方式选择前置到分区规划之前，按选择决定是否创建 BIOS Boot 分区，各组合保留 FAT32 ESP；返回修改选项不立即擦盘，同步调整图形、TTY、挂载切换及分区验证流程。

- 正常桌面启动使用普通 nice 优先级策略：XDM、Xorg 及其输入线程、IceWM 继承 nice=-10，终端及其编译子进程恢复 nice=0；优先级调整失败时仍继续登录。补充并行编译下的实际交互验证与测量说明。

- 交互式 Bash 默认启用 ls、dir、vdir 的自动终端颜色，沿用 GNU dircolors；保留用户已有颜色、分页器与别名配置，尊重 NO_COLOR、TERM=dumb 及非交互模式，管道和重定向使用纯文本输出。

- 修复 RPR 使用相对内核载荷路径时的发布失败；更新锁定的 libde265 到 1.1.3-r0、cups-libs 到 2.4.19-r1 及对应摘要和来源记录。

- 增加 xHCI Hub 的 QEMU 系统集成验证，核对实际键鼠输入、存储读写、子树移除和重建、旧描述符错误及控制器模块装卸；完善 Fileman、安装器和 XDM 测试，更新系统使用与验证边界文档。

破坏性更新
==========

- **否，未新增既有应用入口或磁盘格式的不兼容变更。** 安装器的引导选择顺序和新盘自动布局会按所选固件方式变化；已有安装通过更新流程保留分区。配套内核的内部模块 ABI 更新仍要求整套内核、initramfs、模块及清单匹配，不能混用旧 .ko。

更新与迁移注意事项
==================

- 本次为**正式源码 Release**，只提供标签及 GitHub 自动源码归档，不附预编译 VMDK、ISO、Installer、SDK 或 APK。使用 Git 递归初始化标签固定的子模块；GitHub ZIP/TAR.GZ 不展开子模块。

- 更新前备份用户数据和引导配置，在新的 O 目录重建；复用配置时执行 olddefconfig 并核对内核 y/m/n。ReliefOS defconfig 会同时重置对应 ReliefNT 配置，普通构建保留已有内核设置。

- 新安装仍默认选择 BIOS 和 UEFI 两种引导方式，可分别取消；先完成选择再确认分区方案。更新已有安装不按新盘布局重新分区，保持原有 swap 设置。

- Fileman 自动监听只覆盖当前目录直接子项，不等同于递归监听或搜索。目录被移动、删除、权限不足或事件溢出后，应以重新扫描的结果为准，必要时使用 F5。

- 桌面优先级采用普通调度策略，繁忙交互可能让出部分编译吞吐；终端重新打开后使用正常优先级。颜色配置也在新终端生效，可显式使用 --color=never 关闭单次输出。

- 本次发行检查两仓版本生成、5/3/1 数字宏、VERSION_ID 和严格文档构建，不为本标签重新打包或提供系统镜像。既有单项 QEMU 验证不等于整版复验；**VMware 验证未完成**，物理硬件和完整本机自举未完成验收。

- 内核功能范围、模块迁移和已知宿主测试问题以 ReliefNT 5.3.1 的独立发布说明为准；不将内核历史单项通过推导成所有应用或全部系统测试通过。

开发者提示
==========

- 基础版本为 **5.3.1**，主仓生成数字字段为 **5/3/1**，/etc/os-release 的 VERSION_ID 为 5.3.1；内核版本及模块 ABI 身份由标签固定的 ReliefNT 自行生成。

- 内核实现、UAPI 和原生探针归属 ReliefNT；系统应用、打包、RPR 与完整虚拟机编排归属 ReliefOS。使用各目录 Kbuild 与现行 Documentation 手册，不恢复已退休桌面或私有图形接口。

- 保留 ABI golden 和音频验证策略；不通过重生成基线、修改 BusyBox 或 musl 来掩盖未解决的内核或测试问题。

- 更新范围为 5.3.0 版本提交 **1f5a8756cace6a6b32840c1120e217a151200ddc** 之后至本次版本提交；仅记录主仓最终有效更新，排除内核实现、纯合并和纯 gitlink 更新。下一版以本次版本提交为起点。
