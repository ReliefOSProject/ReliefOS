==============
ReliefOS 5.3.3
==============

更新内容
========

- 控制台安装器改用 ncursesw TUI，与图形向导共用安装和更新后端，提供语言、许可证、磁盘、引导、分区、账户、确认及进度页面。分区页支持可选择的分区表格、容量示意条、空闲区和独立的破坏性操作确认。

- 安装器更新流程复用经过校验的离线缓存，显示阶段、进度和活动详情；更新旧系统时保留仍被引用的旧内核 bundle，避免清理回退启动所需的文件。

- 新增 ReliefSettings，提供当前用户的语言、显示模式和键盘布局设置，以及通过认证修改全系统时区的功能。显示预览支持超时恢复，并整合网络和服务管理入口。

- 自研应用改用各自的 gettext 翻译域，提供日语界面、区域数据和桌面入口；文档及网站新增英文、日文版本和对应的语言导航。

- Fileman 集成可移动存储设备的识别、挂载、打开、安全弹出和占用诊断。Diskmgr、Fileman、安装器与 initramfs 增加 ext3 类型识别和配套操作；手动安装可选择 ext3 根分区，默认自动布局仍使用 ext4。

- 新增 ReliefClipboard，支持 X11 标准剪贴板交接、文本、图片和文件复制粘贴。历史默认跨登录保存，可搜索、暂停记录或清空；Fileman 支持跨实例复制与剪切，Paint 支持图片剪贴板。

- Taskmgr 的启动应用程序页接入 XDG Autostart，支持添加、编辑、启用、禁用、删除或恢复默认项目；IceWM 登录会话使用对应启动器处理标准 Desktop Entry 配置。

- Network Controller 和启动服务按网卡分别管理 DHCP、静态 IPv4、禁用状态和配置备份，汇总各接口的 DNS 信息，并保留旧 eth0 配置的迁移路径。

- X11 默认浏览器切换到 NetSurf，固定其 curl 依赖；更新 Xorg APK 到 21.1.26-r0，并更新失效的 Vim 下载锁及 exfatprogs 1.4.4 依赖。

破坏性更新
==========

- **是，涉及已退役的私有诊断接口和资源路径。** 移除内核诊断会话的用户态接口、独立载荷和镜像集成；依赖旧诊断入口的程序或脚本需要迁移。共享的 leonos 翻译目录改为各应用独立域，自定义翻译必须按新目录和域名安装。没有改变标准 Linux syscall 编号，也不要求转换现有文件系统。

更新与迁移注意事项
==================

- 本次为**源码 Release**，只提供标签和 GitHub 自动源码归档，不附预编译 ISO、磁盘镜像、安装器、SDK 或 APK。递归初始化标签固定的子模块；依赖缓存不足时显式执行 ``make fetch``。

- 设置中心的用户配置遵循 XDG 目录，语言更改在下次登录生效；时区为全系统设置。自启动修改同样在下次登录生效，禁用系统项目通过个人覆盖实现，不删除系统原文件。

- 剪贴板历史默认持久化，可能包含复制过的私密内容；可在设置中关闭“退出登录后保留历史”并清除磁盘历史。私有目录和文件分别使用 0700、0600 权限。

- ext3 使用内部日志和 ``data=ordered``；安装器会在目标 fstab 保存所选文件系统。自动分区仍会擦除所选磁盘，格式化、删除和重新分区前必须核对目标并备份。完整的 ext3 安装器实际安装流程尚未完成验收。

- 发行定向检查覆盖版本头、数字字段、``VERSION_ID`` 和两仓中英日文档。本次未重建发行镜像，也未重新执行完整系统测试；既有功能开发期间的 QEMU 结果不等于整版复验。**VMware 验证未完成**，实体硬件和长期稳定性未完成本版验收。

开发者提示
==========

- ``configs/build-version`` 为 **5.3.3**，生成数字字段为 **5/3/3**，``/etc/os-release`` 的 ``VERSION_ID`` 为 **5.3.3**。ReliefNT v5.3.3 的源码、模块 ABI 和文档由内核仓独立固定，主仓使用对应 gitlink。

- 应用翻译按 ``configs/nls/DOMAINS`` 和 ``configs/nls/LINGUAS`` 构建；修改文案时更新对应应用目录。移除的诊断载荷不影响普通内核符号文件和 debug profile。

- 本次范围为上一版本提交 **451105bced434f9fc941c377f7d5ae9f79c53d62** 之后至本次 5.3.3 版本提交；仅汇总主仓最终生效内容，排除 ReliefNT 实现、纯合并和纯 gitlink 更新。下一版以本次版本提交为起点。
