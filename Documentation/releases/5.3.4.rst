==============
ReliefOS 5.3.4
==============

更新内容
========

- 图形和 ncursesw 安装器统一为逐步向导，分别配置引导、分区、桌面和交换空间，并在写盘前显示安装摘要。IceWM 仍是默认桌面，可选离线安装实验性 XFCE 或纯控制台；改进文件复制和安装进度，并记录失败阶段与文件。

- 新安装 ISO 把桌面、控制台和 ESP 的安装载荷集中到只读 SquashFS，启动时挂到原有安装路径；安装器运行根仍可写，安装后的默认磁盘根仍为 ext4。

- 重写安装器的离线更新：先只读预检再确认写入，分阶段监督 APK 事务和引导发布，保留已有桌面、外部软件包和受保护配置。在线更新改用原生 ``reliefos-update``，支持审阅、续传、失败修复及内核启动载荷回退。

- Xorg 镜像接入 VirtIO-GPU/VirGL 和新的 VMware SVGA II 路径，修复 XDM 在没有用户会话脚本时的选择逻辑；启用试验性 XFCE 的独立 D-Bus 会话，并保留软件显示回退。

- 增加 VirtIO 磁盘的安装、根设备识别及 initramfs 模块集成；修复模块冷插拔失败时 DHCP 不自启的问题。Taskmgr 使用稳定的进程描述符结束任务，Linux 程序可按需经 ``linuxuname`` 启动。

- libbsd、dosfstools、e2fsprogs、util-linux 和 libmd 改用 Alpine 的签名 APK，运行配置统一提供实际的 CA 证书包；CI 分组并行运行，复用构建缓存。

破坏性更新
==========

- **是，涉及旧应用和自制安装介质。** 移除旧 windowd 程序和 browser 使用的 litehtml 子模块；调用旧程序入口的脚本或快捷方式应迁移到仍受支持的 X11 应用。自制安装介质的脚本必须适配独立 SquashFS 载荷；现有磁盘无需转换格式。

更新与迁移注意事项
==================

- 本次为 **源码发布**，不附 ISO、VMDK、SDK 或 APK 二进制。源码构建前请递归同步子模块；计划更新前先备份用户文件和引导分区，检查磁盘空间与信任密钥。

- 离线更新不重新分区或更换桌面；在线更新的回退只覆盖内核、initramfs 和匹配模块，不撤销已提交的普通软件包。旧版若缺少本版需要的引导资源，应使用匹配的安装介质完成迁移。

- XFCE 仍为实验性。QEMU 默认仍使用 AHCI；切换 VirtIO 磁盘需显式选择，且安装器不会在 4Kn 磁盘上执行新建分区或格式化。

- 本次版本检查覆盖版本头、``VERSION_ID``、两仓的中英日文档和文档站点。未重新构建整版镜像或执行完整 QEMU 回归；**VMware 验证未完成**，未重新验证实体硬件。

开发者提示
==========

- ``configs/build-version`` 和 ``/etc/os-release`` 的 ``VERSION_ID`` 均为 **5.3.4**，生成数字字段为 **5/3/4**。内核提交固定为 ReliefNT v5.3.4；不要混用其他版本的模块或 initramfs。

- 发布范围为上一版本提交 ``e6079844756d023d16ca78715b8b3a9d299ac091`` 之后至本次版本提交，仅汇总 ReliefOS 主仓的有效更改；内核实现另见 ReliefNT 发布说明。
