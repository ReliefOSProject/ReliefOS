==============
文件系统与路径
==============

命名与存储
==========

来宾使用 Unix 根目录语义，源码路径不是来宾路径。默认 root 为 ext4，
ESP 独立使用 FAT32；数据分区还可使用已实现的 ext2、FAT32、exFAT 等路径。
支持格式不代表所有 POSIX 权限、崩溃恢复或第三方工具组合均已认证。
GPT 分区名使用 UTF-16，界面文本使用 UTF-8。
具体磁盘管理限制见 :doc:`../applications/diskmgr`。

调用规则
========

文件操作处理短读短写、EOF、EINTR、EAGAIN、权限与最终错误；ret==0
不能代替累计字节校验。路径解析区分符号链接、挂载边界和打开的对象身份。
同目录临时文件、fsync、rename 可发布单文件，不能保证任意多个文件整体回滚。
目录 fsync 不是“同步目录下全部文件”的替代品。

目录枚举使用 Linux ``getdents64``，应用优先使用 POSIX ``opendir/readdir``。
对目录调用 ``read`` 返回 ``EISDIR``。兼容接口 ``reliefos_readdir`` 和
``reliefos_list_dir`` 在运行库内适配标准目录记录，保留发布的结构与符号别名；
不再依赖内核返回私有定长目录记录。调用方应串行操作共享目录描述符的位置。
超过旧定长名称容量时明确返回 ``ENAMETOOLONG``，长名称应使用 POSIX 接口。

块设备操作还需逻辑扇区、只读状态、挂载冲突及分区身份验证。热插拔和同名
媒体替换有未覆盖边界，应保持设备连接并在破坏性操作前再次核对。
