=============
ReliefOS 文档
=============

这里是 ReliefOS 的现行手册。按使用目的进入相应章节，命令均注明运行位置。
支持范围以实际实现为准；Linux ABI 编号或 POSIX 接口名称不代表完整标准认证。
内核内部实现由 ReliefNT 独立文档说明，主仓手册负责用户态、桌面与系统集成。

首次使用请阅读 :doc:`admin-guide/installation`；从源码构建请阅读
:doc:`kbuild/building`。已知限制集中在 :doc:`admin-guide/limitations`。
历史过程记录由 Git 历史保存，不作为当前操作手册。
