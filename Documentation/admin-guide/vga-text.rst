====================
可选 VGA 文本控制台
====================

启用与退出
==========

默认继续使用原有 framebuffer TTY。只有内核命令行包含完整的
``console=vga`` 选项时，才尝试启用独立 VGA Text Mode 后端。
在 GRUB 菜单按 ``e``，将该参数追加到 ``multiboot2`` 行，再启动即可临时验证。
长期配置应修改所用启动项的内核参数，并保留系统更新前的配置备份。
移除该参数，或在它之后添加 ``console=framebuffer``，恢复默认选择。

保留现有 ``gfxpayload=keep`` 和图形设备初始化：内核会把文字控制台切换为
VGA 模式，但仍保留图形设备信息供 Xorg 接管。不要用 ``gfxpayload=text``
代替此参数；没有可用图形后端时不能凭空启动 Xorg。

设备要求
========

该后端使用传统 VGA 端口和显存字符平面，固定为 80 列、25 行、8×16 字体
（通常扫描输出为 720×400）。已实现 Bochs/QEMU Standard VGA 和 VMware
SVGA II 的图形模式恢复接口；是否使用 UEFI 不是唯一判断条件，设备必须实际
提供兼容 VGA 解码。纯 GOP、无 VGA 兼容平面或无法安全恢复图形模式的设备会
输出警告并保留原控制台后端。没有 framebuffer 的 Legacy VGA 设备可用于
纯文字控制台，但无法切换到 Xorg。

终端与图形会话
==============

此模式只替换文字终端后端。登录仍使用原有 getty、``/bin/login`` 和用户配置的
Shell；默认 Bash 继续读取系统和用户的启动配置，并在交互式终端自动运行
fastfetch，随后显示普通命令提示符。没有专用的 VGA 登录程序或测试面板。

``tty1`` 至 ``tty6`` 各自保留主屏、备用屏、光标、属性、滚动区域及分片解析状态，
窗口大小报告为 80×25。登录、termios、进程组、信号、权限与原 VT 子系统共用。
支持原有 VT 快捷键和 Linux VT_PROCESS 交接；Xorg 请求图形模式时恢复图形
设备，切回文字 VT 时恢复对应字符屏幕。GUI 运行期间后台终端输出不写 VGA 显存。
有未释放的 GPU 模式租约、无法完成设备切换时返回错误，不强行拆除 GPU 资源。

支持常用 ANSI/VT 操作：16 色前景和背景、反显和隐藏、光标移动与保存恢复、
清屏清行、字符及行的插入删除、滚动区域与正反向滚动、延迟自动换行、制表位、
备用屏幕、硬件光标显示、设备属性及光标位置查询。256 色和 RGB 请求映射到
最接近的 16 色；UTF-8 按完整字符解析，字库内的拉丁字符和线框符号可显示。
提供应用光标模式、方向键、Home/End、Insert/Delete、PageUp/PageDown、
F1–F12 以及它们的常用修饰组合。

未提供的表现形式
================

* 不绘制 framebuffer 启动画面、位图 logo、图片或任意像素图形。
* 不模拟粗体、细体、斜体、下划线、删除线、字符闪烁及多种字号；相应 SGR
  安全忽略。16 种背景色使用属性最高位，因此不启用硬件字符闪烁。
* 不提供完整中文、全宽 Unicode、组合字形和 emoji 字库；固定字库之外的
  字符显示 ``?``。这不会阻止 GUI 会话继续使用原有字体和中文支持。
* 不提供真正的 256 色/RGB 色深、可变文本行列数、像素鼠标光标、终端内图片、
  窗口标题、剪贴板或超链接。OSC/DCS 等不支持的字符串被完整消费，不泄露到屏幕。
* 光标支持方块和底线形状；竖线光标退化为底线。粗体等字符样式与光标形状是
  不同功能。

VGA 模式只替代文字 TTY。XDM、IceWM 的显示仍是正常图形模式，不能在字符
平面上渲染它们。验证应同时检查文字阶段和进入、退出图形会话的实际显示；
QEMU 的结果不能代替 VMware 或真实硬件验收。
