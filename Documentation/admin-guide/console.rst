============
控制台与诊断
============

VT 与日志
=========

文本 VT 与图形会话共享内核设备，切换时必须正确交还显示和输入。
启动串口日志可用于没有图形输出的情况。内核启动徽标按发现的逻辑 CPU 数量
显示，启动完成前自动移除；它不是物理插槽数量的指示器。
``logcolor=0`` 禁用内核日志颜色，``bootlog-pause=1`` 用于启动日志暂停检查。
不要把只到达 GRUB 页面作为启动成功。

崩溃报告
========

Kernel panic 在当前文本 VT 输出诊断；在 GUI 中从左上角绘制黑底字符格，
保留其他像素。完整诊断继续写串口和 VT 历史。记录异常码、RIP、CR2/CR3、
CPU/任务、内核版本和源码身份，使用同一构建的调试符号定位。
Kerneldebug 的产品信息入口使用 ``About ReliefOS``；诊断工具不能代替正常内核。
没有目标虚拟机故障注入的测试，不能宣称 panic 显示已在该平台通过。
