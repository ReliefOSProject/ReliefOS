==================
Network Controller
==================

网络控制器是使用 C++ 和 FLTK 编写的原生 X11 应用，启动命令为
``network-controller``。支持中文，入口位于系统应用菜单；默认包含在 Xorg 镜像中。
普通用户选择 sudo 密码或 root 密码解锁受限工作进程，GUI 保持原用户身份。
root 账户直接进入。密码不保存在命令参数、环境变量、文件或日志中。

查看与诊断
==========

左侧按实际接口查询结果列出网卡。“概览”显示 IPv4、掩码、网关、MAC、MTU、
解析器。自动刷新只更新状态，不覆盖未保存的配置。若系统导出标准接口计数，则
同时显示收发总量、速率、包数及错误；当前内核尚未导出这些计数，界面明确提示
并隐藏该组字段，不把缺失数据显示为零。网关和连接信息使用已有公开网络查询接口。

“诊断工具”提供 Ping、DNS 查询、TCP 端口测试和 IPv4 子网计算。工具菜单提供
有效路由、TCP 连接、DHCP 租约、解析器、DHCP 日志和诊断报告。诊断命令
异步执行，支持取消、超时与关闭清理；结果在“输出”中保留，可复制或导出。
TCP 连接建立不代表 TLS 校验或目标应用健康；DNS、端口与 Ping 的失败各自报告。

配置与迁移
==========

左侧选择实际枚举的以太网接口并分别编辑；切换网卡前会提示丢弃未保存的修改。
没有 IPv4 地址或处于禁用状态的网卡也会显示。支持自动
DHCP、静态 IPv4 和禁用；静态模式可以不设置默认网关，DNS 必须明确选择
自定义或 Cloudflare。自定义 DNS 最多三个 IPv4 地址，以空格分隔。

eth0 继续使用 ``/etc/reliefos/network.conf``；其他接口使用
``/etc/reliefos/network.d/<接口名>.conf``。未设置的接口默认使用 DHCP。
配置是版本化数据，不作为 shell 脚本执行。静态地址、前缀、网关和 DNS 在 GUI、
工作进程及启动链分别验证，接口名必须对应已枚举的 ``eth`` 加十进制编号。
文件目录和配置必须由 root 所有，不能由组或其他用户写入，不能使用符号链接
替代配置文件或目录。保存检查外部变动，并通过临时文件、同步与 rename 原子
替换；各接口各自保留 ``.bak`` 备份。“恢复上次配置”也检查当前快照，不能
绕过冲突检查。
原先没有配置文件的状态可以恢复为缺省状态。

旧的 DNS-only ``network.conf`` 保持可读；旧 udhcpc DNS 策略在迁移前继续生效。
第一次保存写入完整的新格式并备份旧文件，恢复旧备份后仍能通过原链路启动。
升级时保留本地 ``/etc`` 配置，不要求手动删除旧文件。
版本化 profile 生效后，旧 DNS 写入 API 返回 ``EBUSY``，调用方应通过本程序或
编辑 profile 后重启网络服务调整策略；不会在解析器忽略旧文件时谎报设置成功。
未迁移的旧配置继续支持旧 API。

``reliefos-dhcp`` OpenRC 服务启动时从 ``/proc/net/dev`` 枚举全部以太网卡，
逐卡设置静态/禁用状态或启动各自的 ``supervise-daemon`` 和 DHCP 客户端。
停止或应用某卡时先停其监督器，再校验客户端 PID 及接口参数并等待退出，
然后仅清理该卡地址、默认路由和租约；不会根据刚保存的新模式漏停旧客户端。
eth0 保留原有 ``/run/reliefos/udhcpc.pid``、``dhcp-lease`` 和 ``dhcp-dns``
路径，其他接口的运行状态带接口名后缀。``network-profile`` 独立于可选 GUI，
关闭 GUI 组件不影响基础网络启动。

DNS 解析器由 ``publish-resolver`` 全系统共享并串行发布。先按内核枚举顺序
收集未禁用且未停止接口的显式自定义/Cloudflare 服务器，再收集 eth0 的自动 RDNSS
（仅 eth0 为自动 DNS 时），最后按同一顺序收集自动 DHCP 租约；去重后发布最多
三个地址，多余地址保留在各自租约缓存中。某接口的释放、续租或停用不会删除
其他接口的 DNS 状态。单独 eth0 的旧 DNS-only 和固定 DNS 行为保持兼容。

“仅保存”更改持久化策略，供随后服务重启、DHCP 更新或下次启动读取；
“保存并应用”只重新配置选中的接口，可能中断该接口的连接；如果整个服务
已停止，则由 OpenRC 启动服务并配置全部接口。应用失败时已保存的文件
仍保留，程序显示失败和输出，可修正或恢复备份；不能将保存成功等同于联网成功。

边界
====

当前 GUI 不提供 IPv6 持久化配置；系统的 IPv6/SLAAC、RDNSS 与命令行配置见
:doc:`ipv6`。此 GUI 也不提供 Wi-Fi、VPN、桥接、VLAN、任意静态路由管理或改变内核固定的
MTU。不能将单条 TCP 连接的字节计数冒充网卡总流量。不支持的能力不会显示成已生效。以太网链路能力取决于当前内核和驱动。
QEMU 运行验证与 VMware 实机验证分别记录；VMware 验证未完成。
